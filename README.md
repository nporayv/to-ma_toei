# 都営交通ルート検索

都営交通無料乗車券をお持ちの方のための乗換案内です。

任意の駅から任意の駅まで、**都営線をできるだけ使って運賃をおさえる経路**を探します。
このサービスがいちばん伝えたいのは「**どの駅から都営線に入ればよいか**」です。
経路に詳しくない人でも、出発駅と到着駅を入れるだけで、無料区間の入口と出口が分かります。

## 何が普通の乗換案内と違うのか

一般的な乗換案内は「速さ」で経路を選ぶため、都営線を避けて東京メトロやJRを案内してしまい、
無料乗車券が活かせないことがあります。本サービスは運賃を第一に、時間を第二に評価します。

例: 青砥 → 中野坂上

| | 運賃 | 内訳 |
|---|---|---|
| 一般的な最速経路 | 480円 | 京成 + 都営 + メトロ丸ノ内線 |
| 本サービスの案内 | **100円** | 京成(青砥→押上、手帳割引で半額) + 都営浅草線・大江戸線(すべて無料) |

メトロを使う経路は、単独乗車では割引がきかないため実は高くつきます。
この判断を利用者に代わって行うのがこのサービスの役目です。

## 障害者割引は会社ごとにまるで違う

ここがこのサービスで最も間違えやすく、間違えると実害が出るところです。
**都内の移動はすべて片道100km未満**なので、下表の「100km超のみ」は
実質的に「**ひとりで乗るなら割引なし**」を意味します。

| 事業者 | 単独乗車(介護者なし) | 出典 |
|---|---|---|
| 都営地下鉄・都電・日暮里舎人ライナー | **無料**(無料乗車券) | [交通局](https://www.kotsu.metro.tokyo.jp/other/kanren/fare/free.html) |
| 京成電鉄 | **距離条件なしで5割引**(自社線内完結の場合) | [京成](https://www.keisei.co.jp/keisei/tetudou/accessj/goriyo.php) |
| 北総鉄道 | **距離条件なしで5割引**(第1種・第2種とも) | [北総](https://www.hokuso-railway.co.jp/railway/information.html) |
| 西武鉄道 | 自社線内**50km超**のみ5割引 | [西武](https://www.seiburailway.jp/railway/ticket/ticket/discount/) |
| 東京メトロ | 101km以上のみ5割引 | [メトロ](https://www.tokyometro.jp/ticket/guide/disability/index.html) |
| JR東日本 | 100km超のみ5割引 | [JR東日本](https://www.jreast.co.jp/kippu/yakkan/pdf/disability_discount.pdf) |
| 東急電鉄 | 割引なし(介護者同伴時のみ5割引) | [東急](https://www.tokyu.co.jp/railway/ticket/disability/) |
| 東武鉄道 | 100km超のみ5割引 | [東武](https://www.tobu.co.jp/railway/ticket/disability/) |
| 小田急電鉄 | 101km以上のみ5割引 | [小田急](https://www.odakyu.jp/ticket/discount/) |
| 京急電鉄 | 101km以上のみ5割引 | [京急](https://www.keikyu.co.jp/ride/ticket/unchin_waribiki.html) |
| 京王電鉄 | 101km以上のみ5割引 | [京王](https://www.keio.co.jp/train/ticket/discount/) |
| 上記以外 | 割引なしとして計算(未確認のため安全側) | — |

第1種で介護者と同時に乗車する場合は、どの社も距離条件なしで本人・介護者とも5割引です。
第2種の介護者は割引対象外です(東京メトロは「適用されません」と明記)。

割引がきくのは実質**京成グループ(京成・北総)**だけで、西武が50km超という中間的な基準を持ちます。
このため **「他社線は割引がきかない前提で、都営線をどれだけ使えるか」** が
運賃を決めます。画面には区間ごとに「単独乗車・100km以内のため割引なし」のように
理由を出しています。理由が分からないと、窓口で割引を求めて困ることになるためです。

ルールは `fares.js` の `DISCOUNT_RULES` にまとめてあり、出典URLをコメントに残しています。
**変更するときは必ず各社の一次情報で裏を取ってください。**
実際より安く見積もると、利用者が改札で足りない思いをします。

## 運賃表の確認状況(2026-08-28時点)

運賃改定は思ったより頻繁にあります。取りこぼすと実際より安く案内してしまうので、
下の表の確認日が古くなっていたら見直してください。

| 事業者 | 状態 |
|---|---|
| JR東日本 | 公式運賃表で確認済み(2026年3月13日に電車特定区間・山手線内が廃止され幹線運賃へ) |
| 小田急 | 実際の運賃3区間で校正済み(町田〜本厚木270円 / 新宿〜本厚木520円 / 新宿〜小田原910円) |
| 西武 | 2026年3月14日の運賃改定を反映(池袋〜所沢402円IC / 池袋〜西武秩父800円) |
| 東京メトロ・都営 | 路線が短く(最長40km程度)上限まで表があるため実用上問題なし |
| 京王 | 公式のキロ別運賃表で確認済み(2023年10月改定) |
| 京成・京成松戸線・北総 | 公式の駅別運賃表で全帯を確認済み。営業キロも公式値 |
| 東武 | 営業キロ程表で確認済み |
| 京急・東急・相鉄 | **短距離帯のみ確からしく、長距離帯は推定値** |

長距離帯が推定なのは、都心の移動では届かない距離だからです。ただし遠方を調べると
誤差が大きくなります。正確を期すなら各社の運賃表で差し替えてください。

距離そのものにも誤差があります。駅間の直線距離を足す方式のため、急行線のように
駅間が長い区間では線路の曲がりを拾えず短めに出ます
(例: 吉祥寺〜新宿は推定11.4kmに対し公式12.2km)。

## 使い方

`fetch()` で `network.json` を読むため、`file://` では動きません。ローカルサーバー経由で開いてください。

```bash
python -m http.server 8788 --directory toei-free-transfer
```

ブラウザで `http://localhost:8788` を開きます。ビルド作業やインストールは不要です。

`?from=青砥&to=中野坂上` のように指定すると、その経路を開いた状態で表示します。
支援者が「この行き方です」とリンクで渡せます。

## PWA(スマホのホーム画面に置いて、オフラインで使う)

サービスワーカーがすべての資材(コード + 駅データ、あわせて約150KB)を端末に保存するため、
**いちど開けば地下や圏外でも動きます**。駅の構内で調べられることを想定しています。

- iPhone: Safariで開く → 共有ボタン → 「ホーム画面に追加」
- Android: Chromeで開く → メニュー → 「アプリをインストール」

検索はすべて端末内で行うため、入力した駅名は外部に送信されません。
アクセス解析も入れていないので、利用者の記録は残りません。

## 公開のしかた

静的ファイルだけなので、静的ホスティングならどこでも動きます。
**PWAとして動かすにはHTTPSが必要**です(localhostは例外)。

### GitHub Pages(無料・おすすめ)

`toei-free-transfer/` の中身をリポジトリに置き、Settings → Pages で公開元を指定します。
`https://<ユーザー名>.github.io/<リポジトリ名>/` のようにサブパスで配信されても動くよう、
パスはすべて相対 (`./`) にしてあります。

Netlify、Cloudflare Pages、さくらのレンタルサーバー等でも、フォルダごと置くだけで動きます。

### 更新の手順

運賃改定や駅の新設があったら、データを作り直して置き換えます。
[駅データ.jp](https://ekidata.jp/) にログインしてCSVをダウンロードし、`tools/csv/` に置いてから:

```bash
python tools/build_network.py   # network.json 再生成 + sw.js のVERSION自動更新
```

`sw.js` の `VERSION` が変わると、利用者の画面に「新しいデータがあります／更新する」と出ます。
**この自動更新があるため、VERSIONの書き換え忘れで古い運賃が残り続けることはありません。**
押さなかった場合も、次にアプリを開き直したときに新しい版に切り替わります。

アイコンを作り直す場合は `python tools/make_icons.py` を実行します(Pillowが必要)。

## 経路探索のしくみ

運賃は事業者ごとの通し計算なので、線路1区間ごとに値段を割り振ることができません。
そこで **「駅・いま乗っている事業者・その事業者で乗った距離」** を状態とするラベル法
(多目的ダイクストラ)で探索しています。

- 都営地下鉄・都電荒川線・日暮里舎人ライナーは運賃0円として扱う
- 事業者が変わるところで運賃を確定させ、新しい区間を始める
- 直通運転の路線どうしは乗換時間を加算しない
- 目的駅までの直線距離から所要時間の下界を求め、A*で枝刈りする
- 運賃と所要時間の**パレート最適**な経路を集め、「いちばん安い」と「少し速い」を並べて出す

探索は1件あたり数ミリ秒で終わります。

```bash
node tools/test_router.js   # 動作確認
```

## データについて

駅・路線データは [駅データ.jp](https://ekidata.jp/) の公式CSVを使っています
(`company` / `line` / `station` / `join` の4種)。ダウンロードには会員登録が必要です。
対象は東京・神奈川・埼玉・千葉の**130路線・1628駅**です。

CSVはリポジトリに含めていません(`.gitignore` 済み)。データの出所を一箇所に保つため、
更新するときは必ず駅データ.jpから取り直して `tools/csv/` に置いてください。

[利用規約](https://ekidata.jp/agreement.php)では、商用・非商用を問わず加工・再配布が
認められています(第4〜6条。非加工データを無償で提供する分には制限なし)。
出典表示は義務ではありませんが「歓迎」とされているため記載しています。

このデータの良いところ:

- **`station_g_cd` で公式の乗換駅グループが統合済み**
  (例: 東日本橋＝馬喰横山＝馬喰町、日比谷＝有楽町)
- **`join.csv` に隣接駅の正式データがある** — 路線の並び順から推測するのと違い、
  分岐(鶴見線など)や環状線の閉じ方(山手線・大江戸線)も正しく表現できる
- **`company.csv` で事業者が確定する** — 無料判定を推測ではなく
  「東京都交通局(company_cd 119)かどうか」で行える。ビルド時に対象6路線を検証している
- `e_status` で廃止駅・廃止路線を除外できる

これに加えて、400m以内にある別の駅どうしを徒歩乗換として自動で補っています
(例: 浜松町⇄大門 272m、田町⇄三田 293m)。

路線ごとに駅名が違う乗換駅では、その路線での駅名を表示します
(浅草線なら「東日本橋」、新宿線なら「馬喰横山」)。

### 乗換の負担について

駅データには「その乗換がどれくらい大変か」は入っていません。そこで、改札を出て歩くような
負担の大きい乗換だけ `router.js` の `HARD_TRANSFERS` に手で持ち、所要時間に加算したうえで
画面にも注意書きを出しています(例: 蔵前の浅草線⇄大江戸線は地上を約200m歩く)。
気づいたものがあればこの表に追加してください。

## 制限事項 — 必ずお読みください

- **運賃は概算です。** 駅の緯度経度から営業キロを推定して各社の運賃表にあてはめています。
  都営3線・京成押上線・山手線の公式キロ程で校正していますが(補正係数1.04)、
  実際の運賃と数十円ずれることがあります。
- **時刻表・遅延・運行状況は扱いません。** 所要時間は駅間距離からの目安で、待ち時間を含みません。
- **都バスは対象外です。** 無料乗車券は都バスでも使えますが、本サービスは鉄道のみを扱います。
- **駅名は漢字で入力してください。** 利用しているデータに読み仮名が含まれないため、
  ひらがなだけでは検索できません。
- **割引の適用可否は最終的に各社の窓口の判断によります。** 特にJRの第2種単独乗車の
  100km制限や、各社の端数処理は実際と異なる可能性があります。

## 直通運転を使うときの注意

他社線と都営線をまたいで乗る場合、ICカード式より**磁気式の無料乗車券**のほうが便利です。
ICカード式は入場と出場を同じカードで行う必要があるため、出場時に有人改札での精算手続きが
必要になります([東京都交通局の案内](https://www.kotsu.metro.tokyo.jp/other/kanren/fare/free.html))。

## 無料乗車券の対象

都営地下鉄(浅草線・三田線・新宿線・大江戸線)、都電荒川線、日暮里・舎人ライナー、都バス。
交付対象や申請方法はお住まいの区市町村の福祉窓口にご確認ください。
