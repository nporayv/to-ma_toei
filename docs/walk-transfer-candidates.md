# 徒歩乗換の追加候補

`network.json` の徒歩乗換は「直線400m以内」で自動生成している。
その外側(400〜600m)には**193組**あり、多くは並行する路線の隣どうしで誰も歩かないが、
実際に使われている乗り継ぎも埋もれている。

そこから使えそうなものを抜き出した。**採用するものを選んでください。**

## 追加のしかた

`tools/build_network.py` の `EXTRA_WALK` に1行足すだけ。

```python
EXTRA_WALK = [
    (1130222, 9930408, 450),  # 秋葉原 ↔ 岩本町
    (2800111, 2800313, 440),  # ← こういう行を足す
]
```

距離は下表の「直線」に少し足した値を書く(実際の歩きは1〜2割増しになるため)。
CSVから再生成しても消えない。

## 見送ったもの

- 並行する路線の隣どうし(板橋と北池袋、江ノ島と腰越など)。歩けはするが乗り換えではない
- 観光地・行楽地(箱根、江ノ島、西武園ゆうえんちなど)
- 千葉・銚子など都心から離れた区間
