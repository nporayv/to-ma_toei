# 変更履歴

アプリのバージョンは `sw.js` の `VERSION` を真実の源にしている。
更新するときは必ず日付を進めること(利用者の端末のキャッシュを入れ替えるため)。

## 2026-08-28-3

- 旧worktree(claude/transit-guidance-service-50840a、08-23作業)にあった距離・運賃の
  精度改善を、GitHub版への移行時に漏れていた分もまとめて移植した。
  - `tools/build_network.py`: 公式の累計営業キロ(`EDGE_KM`)から駅間距離を出す仕組みと、
    路線ごとの公式全長(`LINE_KM`)から距離補正係数を路線単位で求める仕組みを追加。
    対象は京成グループ(本線・押上線・金町線・千葉線・千原線・松戸線)・北総線・JR中央線。
    これまでは全路線一律の係数(1.04)で駅間距離を推定していた。
  - 京成松戸線(旧・新京成線)を本線と別の運賃体系として分離(`keisei_matsudo`)。
    以前は本線と同一路線扱いで、松戸線をまたぐ経路が実際より安く出ていた。
  - 北総線の運賃表を公式値に更新。以前は上限660円で、印旛日本医大方面(32.3km)が
    実際820円のところ660円と**160円安く**出ていた(`node tools/test_fares.js`で検知)。
  - 上記の路線別補正係数の導入にともない、明示指定のない路線が「その他」事業者の
    中央値に引きずられる副作用が発生(強羅→小田原が実際よりさらに安く出る回帰)。
    箱根登山鉄道の公式全長(15.0km)を`LINE_KM`に追加して解消。
  - 距離・運賃の安全網 `tools/test_fares.js`(実測27件との突き合わせ、安く出たら不合格)
    を移植。移行時にこの種の後退が起きても次のセッションで機械的に検知できるようにした。
  - `tools/csv/`(駅データ.jpのCSV、.gitignore対象)をこのクローンにも配置。
  - 出典・経緯は `docs/fare-sources.md`・`docs/data-requests.md` を参照。

## 2026-08-28-1

- 京成電鉄の運賃表を公式の駅別運賃表(2025年4月1日時点)から作り直した。
  以前は営業キロ6km超10km以下をすべて270円としていたが、実際は9.9kmまで200円、
  10km超で280円で、そもそも京成に270円という運賃は無い。このため7〜9kmの区間を
  高く見積もっていた(京成八幡→青砥 7.6km を270円→**正しくは200円**)。
  京成上野・京成八幡の駅別運賃表94点ときっぷ運賃が完全に一致することを確認済み。
  あわせて 押上→京成立石(4.5km)・押上→四ツ木(3.1km)も200円→170円に是正。
  出典は `docs/fare-sources.md`。

## 2026-08-27-2

- 徒歩乗換を42組追加(候補54組から利用者が選定)。都営線につながる組を
  中心に採用したため、一部の区間で実費(無料乗車券利用時)が下がった:
  北参道→川崎大師 510円→330円、横浜→舞浜 550円→500円。

## 2026-08-27-1

- 東京メトロと都営地下鉄の乗継割引を通常運賃に反映(`fares.js` の `TRANSFER_DISCOUNT`)。
  従来は事業者ごとの運賃を単純に足していたため、両社を乗り継ぐ経路で
  通常運賃を高く見積もっていた(舞浜→押上で 660円 → 590円)。
  実費(無料乗車券利用時)は変わらない。無料乗車券の利用者はメトロ側を
  単独のきっぷで買うため、そもそも乗継割引が適用されないため。
- 割引が効いた経路には、その旨を画面に明記(内訳の合計と一致しないため)。
