# 変更履歴

更新するときは必ず日付を進めること(利用者の端末のキャッシュを入れ替えるため)。

- 秋葉原(JR・日比谷線・TX)と岩本町(都営新宿線)の徒歩連絡を追加(直線415m・自動生成の閾値400mを外れて漏れていたもの)
