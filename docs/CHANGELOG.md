# 変更履歴

アプリのバージョンは `sw.js` の `VERSION` を真実の源にしている。
更新するときは必ず日付を進めること(利用者の端末のキャッシュを入れ替えるため)。

## 2026-09-02-1

見た目を利用者が選べるようにした。見え方の負担は人によって大きく違うため、
1つを正解として押しつけず、7つの意匠から選べる形にしている。

- **デザイン(意匠)を7種類から選べるようにした。** ヘッダのプルダウンで切り替える。
  選んだ意匠は端末の中に保存し、次に開いたときも同じ見た目で出る(外部には送らない)。
  - 明朝 … 規約ページと同じ作法。明朝の見出し、細い赤罫、余白で読ませる
  - サインボード … 駅の案内サイン。太い赤帯、黒の極太罫、角ゼロ
  - きっぷ … 乗車券を模す。生成りの紙色、ミシン目の破線、等幅の数字
  - ブロック … 3pxの黒枠と段差の影。輪郭で要素を分ける
  - 路線図 … 駅は白抜きの丸、区間は丸端の太線
  - やわらか … 角を大きく、影を薄く、赤を一段落とす
  - 初代 … Ver 1.00 まで既定だった配色と形
- **既定の意匠を「明朝」にした。** 従来の既定は「初代」という名前で選べるまま残してある。
- **表示色(デフォルト／明るい／暗い)の3種類はそのまま。** 意匠と組み合わせるので
  7×3=21通りになる。21通りすべてで本文・見出し・ボタンの文字と地の
  コントラスト比が4.5:1以上あることと、横スクロールが出ないことを確認済み。
  「やわらか」の赤は `#d8434a` では白抜き文字が4.36で基準に届かなかったため
  `#d03d44` に一段暗くした。
- **Webフォントは使わない。** 意匠の見本はGoogle Fontsで作ったが、このアプリは
  電波が届かない場所で使う前提のため、外部から書体を読むと初回オフライン時に崩れる。
  端末に入っている明朝・ゴシック・等幅で組んでいる。
- ヘッダのタイトルを「とるけん」+ 小さく正式名称「－都営交通ルート検索ツール」に変更。
  正式名称は利用規約・プライバシーポリシーの表記に合わせた。`<title>` も同じに揃えた。
- ヘッダのバージョン表示をページ右端に寄せ、表記を **「RayV トーマ @Ver 1.00」** に変更(暫定)。
  タイトルと重ならないよう、絶対配置をやめてヘッダ内の独立した行にしている。
- 到着駅側に残っていた「よく使う駅」の空欄を削除。Ver 1.00 で出発駅のみ保存に
  変更した際の消し残りで、画面にも出ず、どこからも参照されていなかった。

### 利用規約ページ

- 冒頭の「提供　NPO法人新・障害者支援機構RayV」の下に、**公式サイト**と
  **X（旧Twitter）** のURLを掲載した(どちらもリンク、別タブで開く)。

### 既定の意匠を変えたことに伴う整合

既定が「初代」から「明朝」に変わったのに、アプリの外側に出る設定が初代のままだった。

- `manifest.webmanifest` の `name` が旧アプリ名「とるけん-都営ルート優先検索アプリ」の
  ままだった。**ホーム画面に追加したときの表示名になる**ため、正式名称に修正。
- `theme_color` / `<meta name="theme-color">` を初代の赤 `#d02a2b` から
  既定意匠(明朝)の `#c0272d` に変更。ブラウザのアドレスバーやタスク切替の色に出る。
- `background_color` を `#f4f5f7` から明朝の地色 `#ffffff` に変更。
- `<meta name="description">` と manifest の `description` を、変更後の説明文に合わせた。

### 文言の統一

- 「5駅までデバイスの内部に保存できます」→「5駅まで端末の中に保存できます」。
  他の箇所はすべて「端末」で書いており、ここだけ「デバイス」だった。
- 画面先頭の読み飛ばしリンク「検索結果へskip」→「検索結果へ移動」。

### ヘッダ・フッターの表記

- **「とるけん」の由来が読み取れるようにした。** 正式名称の
  「**都**営交通**ル**ート**検**索ツール」の3文字だけ色を変えている(太字にはしない)。
  「明るい」は地が赤で赤の強調が効かないため、この表示色のときだけ黄で抜く。
- 正式名称のうしろに **提供：NPO法人RayV** を添え、`https://x.com/rayv_staff` へのリンクにした。
- ヘッダの説明文を「都営交通を優先的に利用するための乗り換え案内ツールです。
  利用にあたっては**利用規約**に同意のうえ、ご利用ください。」に変更(利用規約はリンク)。
- バージョン表示の囲み(背景・枠)を外して文字だけにした。目立たせる必要がないため。
- デザインの選択を表示色と同じ行の左側に移した。
- フッターの「ホーム画面に追加しておくとアプリのように使えます」を改行して下線で強調。
- **補助文字の色を3意匠で濃くした**(明朝 `#7a7a7a`→`#747474`、きっぷ `#8a8074`→`#7b7165`、
  やわらか `#8c7e82`→`#7d6f73`)。従来の値では地とのコントラストが3.84〜4.29しかなく、
  基準の4.5に届いていなかった。ヘッダに小さい文字が増えたため合わせて是正した。
  21通りすべてで、ヘッダの各文字と本文の補助文字が4.5:1以上あることを実測確認済み。

## 2026-08-31-1

公開前の総点検。乗換案内サービスと各社公式ページで運賃を独立検証した。

- **東京メトロの上限運賃を340円→330円に是正。** 公式の普通券運賃表で全帯を確認した
  (1〜6km:180 / 7〜11km:210 / 12〜19km:260 / 20〜27km:300 / 28〜40km:330)。
  実際より10円高い=安全側の誤りだったが、根拠のない値だった。
  未実装の特殊区間(千代田線 綾瀬〜北千住160円、南北線 目黒〜白金高輪180円)も記録した。
- **JR東日本の運賃改定日の記載を3月13日→3月14日に訂正。** 公式は14日購入分から。
  13日までに買ったきっぷは乗車日が14日以降でも旧運賃、という関係だった。
  電車特定区間・山手線内が廃止され幹線に統合された点は公式で確認済みで、実装は正しい。
- 実運賃3点を `tools/test_fares.js` に追加(中野〜東中野160円、渋谷〜新宿200円、
  三鷹〜新宿260円)。検証点は27→30件になり、**安く出る区間は引き続き0件**。
- **`tools/test_single_route.js` が合否を出さないようにした。** 社ごとの金額比較では
  合否を決められない。同じ事業者でも本サービスと実データで乗る区間が違うことがあり、
  直通運転では内訳の切り方も一致しないため(渋谷〜みなとみらいは実データが東急310+MM200、
  本サービスが東急320+MM190。合計はどちらも510円で正しい)。
  従来はこの比較で10区間中7区間に「改札で足りなくなる」という誤警告が出ており、
  正しい実装を疑わせる状態だった。運賃表の合否は `test_fares.js` の担当に一本化した。
- READMEを現状に合わせた。存在しない `toei-free-transfer/` を指していた起動手順、
  距離の求め方の説明、ファイル構成表を修正し、Windows PowerShellでの実行方法と
  ローカルでのデバッグ手順(サービスワーカーのキャッシュの外し方)を追記した。

## 2026-08-29-1

- アプリのアイコンを差し替えた。街の格子を一本の経路が抜けていく図(「最短」案)。
  旧アイコンは生きものの顔に見えるという指摘があり、原因は
  (1)角丸の枠が輪郭=頭に見える (2)中身が縦一本の左右対称で顔の中心線と一致する
  (3)白抜きドーナツ状の点が瞳孔の形をしている、の3つが揃っていたこと。
  新しい図は横方向の折れ線・左右非対称・枠なし・白抜きの点なしで、3つとも外している。
  **この3条件を復活させないこと**(`tools/make_icons.py` の冒頭に明記した)。
- 旧版は「白地だと明るいホーム画面で輪郭が消える」ため赤い枠を付けていたが、
  枠が顔に見える原因だったので廃止。代わりに格子を端まで伸ばし、地紋に範囲を示させている。
  余白のある見た目に戻す場合は `make_icons.py` の `GRID_BLEED` を `False` にする。
- 意匠上の制約は従来どおり(赤十字は条約・国内法で禁止、ヘルプマークは東京都の登録商標)。
  今回あらたに、**赤ベタの角丸四角はヘルプマークの第一印象そのもの**なので地は白のままとした。
  花・笑顔・ハート・手など福祉を直接連想させる記号も使っていない。
- マスカブル(Androidで円に切り抜かれる)は経路だけを0.74倍して安全域に収めた。
  32pxのファビコンは格子がつぶれて濁るため格子を省き、経路を少し太くしている。
