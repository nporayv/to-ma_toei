# 変更履歴

アプリのバージョンは `sw.js` の `VERSION` を真実の源にしている。
更新するときは必ず日付を進めること(利用者の端末のキャッシュを入れ替えるため)。

## 2026-08-27-2

- 徒歩乗換を42組追加(候補54組から利用者が選定)。都営線につながる組を
  中心に採用したため、一部の区間で実費(無料乗車券利用時)が下がった:
  北参道→川崎大師 510円→330円、横浜→舞浜 550円→500円。

## 2026-08-27-1

- 東京メトロと都営地下鉄の乗継割引を通常運賃に反映(`fares.js` の `TRANSFER_DISCOUNT`)。
  従来は事業者ごとの運賃を単純に足していたため、両社を乗り継ぐ経路で
  通常運賃を高く見積もっていた(舞浜→押上で 660円 → 590円)。
  実費(無料乗車券利用時)は変わらない。無料乗車券の利用者はメトロ側を
  単独のきっぷで買うため、そもそも乗継割引が適用されないため。
- 割引が効いた経路には、その旨を画面に明記(内訳の合計と一致しないため)。
