# 運賃計算のために必要なデータ(提供10区間からの洗い出し)

いただいた10区間を `node tools/test_10routes.js` で実際に流し、
**いまのデータでは正しい運賃が出せない箇所**を特定したものです。
「何がいるか / いらないか」への回答として、優先度順にまとめます。

結論を先に書くと、**経路探索そのものは10区間すべてで動きます**。
足りないのは運賃側、とくに次の3つです。

1. 各社の運賃表が短距離までしか無く、それより遠いと頭打ちになる
2. 駅間距離が緯度経度からの推定で、営業キロではない
3. 直通運転の会社境界と加算運賃が入っていない

---

## 1. 各社の運賃表(最優先・実費に直結)

`fares.js` の運賃表は都内近距離を想定した距離帯しか持たず、
**最後の区切りより遠い区間はすべて同じ運賃**になります。
データに入っている路線の長さと比べると、次のように足りていません。

| 事業者 | 運賃表の最終区切り | データ上の最長路線(推定) | 影響 |
|---|---:|---:|---|
| JR東日本 | 60km | 234km | 電車特定区間の表しか無い(幹線・地方交通線の表が無い) |
| 東武 | 21km | 116km | 遠距離が一律370円 |
| 小田急 | 23km | 82km | 遠距離が一律330円 |
| 京成 | 30km | 76km | 遠距離が一律560円 |
| その他鉄道 | 10km | 70km | 箱根登山・伊豆箱根・江ノ電などを一律400円で代用 |
| つくばエクスプレス | 20km | 57km | 遠距離が一律470円 |
| 京急 | 25km | 57km | |
| 西武 | 21km | 55km | |
| 相鉄 | 14km | 51km | |

これが8番「強羅 → 京成立石」で露骨に出ます。現状の出力は

- 箱根登山鉄道 強羅→小田原 11.7km = **400円**(`その他鉄道` の一律運賃)
- 小田急 小田原→新宿 78.9km = **330円**(表の最終区切り23km以降が全部330円)

となり、実際よりかなり安く案内してしまいます。
利用者が改札で足りない思いをする、いちばん避けたい向きの誤りです。

**お願いしたいもの(どちらか一方で構いません)**

- (A) 各社の公式運賃表 — 距離帯と運賃の対応。**きっぷ運賃とIC運賃の両方**、および**改定日**
- (B) それが手に入らない場合は、公式運賃ページのURL一覧。こちらで距離帯を書き起こします

対象は少なくとも次です(数字が動く順):
JR東日本(電車特定区間 / 山手線内 / 幹線 の3表)、小田急、東武、京成、
つくばエクスプレス、京急、相鉄、西武、東急、京王、東京メトロ、都営(無料でも「本来の額」表示に使う)。

余裕があれば、その他扱いになっている
箱根登山鉄道、伊豆箱根鉄道、江ノ島電鉄、千葉都市モノレール、流鉄、ユーカリが丘線、
金沢シーサイドライン、秩父鉄道、芝山鉄道、小湊鉄道、いすみ線、銚子電鉄、湘南モノレール、
ニューシャトル、ディズニーリゾートライン も欲しいです。

## 2. 営業キロ(公式の駅間距離)

いまは駅の緯度経度から直線距離を出し、補正係数1.04をかけて営業キロを推定しています
(`fares.js` の `ROUTE_FACTOR`)。都営3線・京成押上線・山手線で校正しましたが、
カーブの多い路線や長距離では距離帯をまたいで運賃が1段ずれます。

**お願いしたいもの**

- 各社のキロ程表(営業案内・鉄道要覧の駅間キロ)、または
- 国土数値情報「鉄道」(N02)のような公的な線形データ

路線ごとの「起点からの累積キロ」の形が最も使いやすいです。
これが入れば推定をやめて実キロで計算でき、1のデータと合わせて運賃が確定します。

## 3. 直通運転の会社境界と加算運賃

4番「渋谷 → みなとみらい」で、**相鉄・JR直通線の渋谷〜西谷 34.5kmを丸ごと相鉄運賃**として
計算してしまっています(相鉄運賃270円)。実際には羽沢横浜国大でJRと相鉄に分かれ、
両社の運賃を足したうえで加算運賃もかかるため、大幅な過小評価です。
駅データ.jp の路線データは「相鉄・JR直通線」を1路線1社として持つため、
**運賃計算上の会社境界を別に持つ必要があります**。

**お願いしたいもの**

- 直通区間の運賃計算上の境界駅の一覧
  (相鉄・JR直通線=羽沢横浜国大、相鉄/東急新横浜線=新横浜、
  京成⇔都営⇔京急=押上・泉岳寺、都営三田線⇔東急目黒線=目黒、
  メトロ⇔東武・西武・小田急、JR⇔りんかい線=大崎 など)
- 加算運賃の一覧(京急空港線、東急・相鉄新横浜線、京成成田空港線、北総線 など)
- 連絡運輸の特例・乗継割引(都営⇔東京メトロの乗継割引、社局をまたぐ通算の有無)

なお都営線は無料乗車券で0円なので、**都営が絡む乗継割引は運賃には効きません**。
必要なのは「他社どうしが通算されるか」の情報です。

## 4. 障害者割引まわりで確認したいこと

`fares.js` の `DISCOUNT_RULES` は各社の公式ページを根拠にしていますが、
運用の細部が分かりません。次が分かると精度が上がります。

- 端数処理: 半額後の10円未満を切り上げるか切り捨てるか(社ごとに違う可能性)
- IC運賃に割引を適用したときの1円単位の扱い
- 連絡乗車券にした場合の距離条件の通算(京成が線内完結扱いでよいかの裏取り)
- 新京成の京成松戸線への統合(2025年4月)後、京成本線との運賃が通算されるか
  — 5番「松戸 → ユーカリヶ丘」がこれに該当します
- 都営無料乗車券が他社直通列車に乗ったまま都営区間を通過する場合の扱い

## 5. いちばん助かるもの — 10区間の「正解」運賃

上のデータが揃うまでの間も、**この10区間の実際の運賃(できれば経路つき)**を
いただけると、そのまま回帰テストの期待値にできます。
`tools/test_10routes.js` の `CASES` に expected を持たせる用意はしてあります。

単独乗車(第2種・介護者なし)、きっぷ運賃、都営線は無料、という前提での金額をお願いします。

## いらないもの

参考までに、以下は**不要**です(すでに揃っている、または使いません)。

- 駅の一覧・座標・隣接関係 — 駅データ.jp のCSVで足りています(130路線1628駅)
- 時刻表・ダイヤ・遅延情報 — 本サービスは所要時間を距離からの目安としてしか使いません
- 都バスの系統・運賃 — 鉄道のみが対象です
- 定期運賃・回数券・企画乗車券 — 片道普通運賃だけを扱います
