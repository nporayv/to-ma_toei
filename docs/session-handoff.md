## アプリの趣旨(最重要・常に意識すること)

**都民の近距離移動専用**。東京都から都営交通無料乗車券をもらっている方が  
出発駅→目的駅を都営交通経由で調べるツール。  
NPO法人新・障害者支援機構RayVが提供。  
- 県境越え・山岳エリア・海沿い神奈川などは対象外  
- 都バスは鉄道でないため対象外  
- 1円単位の精度追求は不要。スコープ膨張に警戒

## 技術的な重要事項

### 距離計算
- **公式営業キロあり**: 京成本線・押上線・金町線・千葉線・千原線・松戸線、北総線、JR中央線
  → `tools/build_network.py` の `EDGE_KM` に累積キロを保持
- **それ以外**: 緯度経度→直線距離×補正係数(`LINE_KM`から計算)
- 公式全長未登録路線は同事業者の中央値を使用(箱根登山はこれで問題が出た→個別登録済)

### 運賃表の精度(2026-08-31確認済み)
- 東京メトロ: 上限330円(5帯すべて確認済み)
- JR東日本: 2026-03-14改定後の幹線運賃
- 京成: 公式駅別運賃表94点で確認済み
- 京成松戸線(旧新京成): `keisei_matsudo` として本線と分離
- 北総: 公式値に更新済み(上限820円)
- test_fares.js: 30件の実測との突き合わせ → 安く出る区間は0件

### よく使う駅の保存
- localStorage使用(端末内のみ、外部送信なし)
- 最大5駅、出発駅のみ保存(Ver 1.00から)
- 「ためしに」セクションの例にも使用される

### SERVICE WORKER / キャッシュ
- VERSIONを変えるとユーザー端末のキャッシュが入れ替わる
- `tools/build_network.py` 実行で自動更新される
- 手動で上げる場合は `sw.js` の `const VERSION` を変更

## 既知の課題・未対応事項

### 運賃精度の問題(スコープ内・改善余地あり)
| 区間 | 現状 | 実際 | 差 |
|------|------|------|-----|
| 流山おおたかの森→武蔵小杉 | 670円 | 920円 | -250円 (TX, 東急) |
| 横浜→舞浜 | 520円 | 未確認 | 相鉄長距離帯が推定値 |
| 強羅→京成立石 | 830円 | 未確認 | 箱根登山・小田急長距離帯が頭打ち |

これらはアプリの趣旨(都民の近距離移動)から外れた遠距離区間のため、  
**緊急度は低い**。利用者が実際に使う区間は都内近距離がほとんど。

### 直通運転の会社境界(未実装)
- 相鉄・JR直通線: 羽沢横浜国大での境界が未実装 → 渋谷→みなとみらいが安く出る
- 同様に相鉄/東急新横浜線も

### 受領済みだが未反映のデータ
- 国交省N02(全国路線形状GML): 受領済み・未反映。取り込むと全路線で実距離補正が可能。
  ただし都民近距離移動の趣旨から見ると優先度は中程度。
- `passenger_fare.pdf`, `use_pasmo.pdf`, `西武鉄道unchin20260314.pdf`: 受領済み・未反映

## 運用メモ

### ローカルデバッグ方法
```
python -m http.server 8788
```
→ `http://localhost:8788` で開く  
変更が反映されない場合: `Ctrl+Shift+R` → だめなら F12→Application→Service Workers→Unregister

### 運賃テストの実行
```
node tools/test_fares.js
```
安く出たら不合格。実測30件との突き合わせ。

### network.json再生成(駅データ更新時)
```
python tools/build_network.py
```
→ network.json更新 + sw.jsのVERSION自動更新
